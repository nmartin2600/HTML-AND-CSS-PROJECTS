# HTML and CSS Projects
This repository contains sample websites that I created using HTML and CSS.

## Projects

### The Pet Shop
[This project](https://github.com/nmartin2600/HTML-AND-CSS-PROJECTS/tree/main/The-Pet-Shop-Website) is an example website for a pet shop. It's styled using CSS, with the home page containing a navbar, image and video containers, and a footer. The navbar also links to a contact page that has a form.

### Simple Recipes
[This project](https://github.com/nmartin2600/HTML-AND-CSS-PROJECTS/tree/main/Simple-Recipes) is an example for a recipe website. It's styled using CSS, feautring a navbar with a rollover menu, image containers with animated effects, form, and footer.

### Academy Cinemas
[This project](https://github.com/nmartin2600/HTML-AND-CSS-PROJECTS/tree/main/Academy-Cinemas) is an example for a movie theatre website that is styled using Bootstrap 5.2. It contains many Bootstrap elements such as a navbar, cards, dropdown menus, and automatic resizing using the grid system of the framework.
